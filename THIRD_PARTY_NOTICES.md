# Third-party notices

## monogram pixel font

The file `src/rayscreen/assets/monogram-extended.ttf` is bundled so that the default theme works without a separate assets package.

Monogram is a free, Creative Commons Zero (CC0) pixel font made by Vinícius Menézio (@vmenezio).

- Project: https://datagoblin.itch.io/monogram
- License: https://creativecommons.org/publicdomain/zero/1.0/

The font's original credits also give special thanks to:

- Ateş Göral (@atesgoral) for creating the bitmap font converter: https://codepen.io/atesgoral/details/RwGOvPZ
- Éric Araujo (@merwok_) for the initial port of monogram to PICO-8: https://itch.io/post/2625522
